## Отчёт: структура и содержание

Отчёт оформлен по ГОСТ (Times New Roman 14 пт, полуторный интервал,
поля 30/15/20/20 мм, отступ первой строки 1,25 см, выравнивание по ширине);
все формулы вставлены как редактируемые объекты OMML (уравнения Word),
нумерация формул — по разделам: (2.1)–(2.11), (4.1)–(4.5), (5.1)–(5.4), (6.1)–(6.11).

1. **Трёхсторонний протокол распределения ключей** — протокол Нидхэма–Шрёдера
   (1978): роли A, B и доверенного центра T, пять шагов обмена, итоговый
   результат (сеансовый ключ K_AB между A и B), атака Деннинга–Сакко и
   варианты защиты (метки времени в Kerberos, нонсы в версии 1987 г.,
   протокол Отвея–Рииса).
2. **Формальные модели шифров** — пять моделей: алгебраическая, вероятностная
   (критерий Шеннона, совершенная секретность), симметричного и асимметричного
   шифров (RSA), блочного шифра, автоматная; у каждой — определение, свойства,
   пример и назначение.
3. **Принципы построения поточных систем шифрования** — девять принципов в
   четырёх группах (стойкость: длинный период, статистическая неотличимость,
   нелинейность, однократность гаммы; корректность: синхропосылка,
   обратимость и ресинхронизация; эффективность: скорость и экономичность
   ключа; надёжность: ошибкоустойчивость), критерии Рюппеля.
4. **Режим без требования биективности** — CFB (а также CTR, OFB):
   расшифрование использует только прямое преобразование E_k, однозначность
   обеспечивается структурой режима и обратимостью XOR.
5. **Распространение ошибки в режиме CFB** — при 64-битовом регистре,
   8-битовых сегментах шифртекста и 64-битовых блоках текста одиночная ошибка
   искажает ровно два 64-битовых блока открытого текста (1 бит напрямую +
   восемь сегментов через искажённую гамму; иллюстрация в таблице 1).
6. **Коллизия случайной пары сообщений** — модель «парадокса дней рождений»:
   из 2^-n ≤ 10^-9 следует n ≥ 9·log2(10) ≈ 29,897, ответ n = 30
   (проверка обеих сторон границы; замечание о границе 2^(n/2) для
   противника, ищущего коллизии).

## Интерактивные схемы

Обе схемы — самодостаточные HTML-файлы (HTML + CSS + JS без зависимостей,
сборка не требуется, интернет не нужен).

- **1q_key_distribution_protocol.html** — пошаговая анимация протокола
  Нидхэма–Шрёдера: роли сторон, пять шагов обмена сообщениями, содержимое
  каждого шифртекста, а также демонстрация атаки Деннинга–Сакко (повтор
  старого билета).
- **2q_formal_models_of_ciphers.html** — карточки пяти моделей шифров:
  определение, компоненты, ключевое соотношение (D_k(E_k(x)) = x,
  критерий Шеннона P(x|y) = P(x) и др.) и рабочий пример с параметрами;
  прогресс изучения и сводка внизу страницы заполняются по мере открытия
  карточек, есть кнопка «⟲ Сброс прогресса».

**Как открыть:** двойной клик по файлу — страница откроется в браузере
(Chrome, Firefox, Edge — любой современный). Запуск веб-сервера не требуется.

## Цветовая палитра (общая для всех схем курса)

| Переменная | Значение | Назначение |
|---|---|---|
| `--bg` | `#f4f6fa` | фон страницы |
| `--blue` | `#007bff` | нейтральное состояние карточки/шага (idle), акценты |
| `--green` | `#1bdb21` | активное состояние (текущий шаг, открыта карточка) |
| `--green-point` | `#1f9d55` | отметка «изучено/выполнено» |
| `--red` | `#dc3545` | ошибки, атака, нарушение условия |

Шрифт формул и обозначений — `Consolas`; прочий текст — системный sans-serif.
Семантика состояний единообразна: синий — неактивно, зелёный — активно,
тёмно-зелёный — завершено, красный — проблемная ситуация. Новые схемы курса
стоит оформлять по той же палитре.
