# Формальные модели шифров

Интерактивная учебная схема по **вопросу 2 «Формальные модели шифров»**: пять моделей криптографии на одной странице, каждая — с рабочим примером и настраиваемыми параметрами.

## Что это

Страница визуализирует классификацию формальных моделей шифров, восходящую к работам К. Шеннона:

- **алгебраическая** — шифр как пара преобразований с соотношением `D_k(E_k(x)) = x` и требованием `|Y| ≥ |X|`;
- **вероятностная** — распределения P(X), P(K) и критерий совершенной секретности `P(x | y) = P(x)` (шифр Вернама, условие `|K| ≥ |X|`);
- **симметричная / асимметричная** — различие в устройстве ключей, односторонние функции с секретом;
- **блочная** — подстановка на `V_n`, сравнение со случайной подстановкой;
- **автоматная** — поточное преобразование знаков конечным автоматом.

Каждая модель подаётся как интерактивный пример: карточку можно открыть и поэкспериментировать с параметрами. Модель считается изученной, когда её карточка раскрыта.

## Как пользоваться

1. Откройте страницу в любом современном браузере (достаточно двойного клика по `index.html` — сервер не нужен).
2. Изучайте модели, раскрывая карточки: сводка внизу страницы заполняется по мере прохождения.
3. Если нужно пройти всё заново — кнопка **«⟲ Сброс прогресса»** сбрасывает состояние карточек и сводки.

## Сводка моделей

Таблица внизу страницы собирается автоматически: №, модель, ключевое соотношение, комментарий. Когда все карточки открыты, появляется итоговый вывод о взаимодополняемости моделей и блок предупреждений об ограничениях (алгебраическая модель не учитывает противника; совершенная секретность требует однократной гаммы и на практике недостижима — стойкость лишь вычислительная).

## Структура страницы

```
index.html
├── Панель «Заголовок + подзаголовок»   — постановка вопроса 2
├── Панель «Разбор моделей»             — карточки моделей (интерактив)
├── Панель «Сводка моделей»             — автозаполняемая таблица + итог + ограничения
└── Кнопка «⟲ Сброс прогресса»          — управление
```
